# FastTxt

A tiny, fast text editor for Windows, written in Python (tkinter). I made it because Notepad has no "Copy All" button.

## Features

- **Copy All** button: copies the whole document in one click
- **Clear**, **Open**, and **Save** buttons
- **Ctrl+S** saves to the file you opened, with no Save As box every time
- Warns you about unsaved changes before closing
- Line numbers that scroll with your text
- Status bar with line, column, and word count
- Zoom with **Ctrl + mouse wheel**
- Dark mode toggle
- Opens a file passed to it, so it can be set as your default .txt editor

## Download

[Download the .exe](https://github.com/cathlyn-exe/FastTxt/releases/latest)

No Python needed. Windows may show a warning because the app is unsigned. That's normal for small self-made programs.

## Run from source

Requires Python 3.

    python fasttxt.py
