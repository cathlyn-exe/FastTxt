# FastTxt

A tiny text editor I made in Python (tkinter) because Windows Notepad has no "Copy All" button.

Features: Copy All, Clear, Open, Save, and live line numbers.

[Download the .exe](https://github.com/cathlyn-exe/FastTxt/releases/latest)
